# 峡谷瀑布网站背景执行包

## 1. 背景设定

- 用途：AI Animation Director 网站首屏背景。
- 交互：页面滚动进度控制视频前进与回放。
- 时长：约 10 秒，单一连续镜头。
- 文案安全区：左侧中部；瀑布和人物保持在右侧。

## 2. IMG-WEB-HERO

复制提示词：
```text
横向 16:9 网站首屏环境关键帧，辽阔的高山峡谷与右侧高耸瀑布为主视觉。前景是深色湿润岩石和少量苔藓，形成稳重框景；中景是明亮黄绿色草坡、蜿蜒溪流与右下方极小的旅行者剪影；背景是层叠深灰蓝山壁、低云和空气透视。冷雾蓝与炭灰为底色，瀑布白和草坡黄绿形成明亮焦点，柔和天光从右上方穿过云层。左侧中部保留低细节、低高亮、可承载白色标题的文案安全区，右侧瀑布轮廓清晰。电影概念场景绘画质感，宽阔空间层次，笔触可见但结构准确，细节丰富而不杂乱，无文字、无 Logo、无水印、无签名。
```

## 3. VID-WEB-HERO

使用图片：`IMG-WEB-HERO`

复制提示词：
```text
以 IMG-WEB-HERO 为唯一画面参考，生成约 10 秒单一连续网站背景镜头。起始状态：峡谷晨雾停留在中远景，瀑布稳定下落，草坡和旅行者位置完全固定。结束状态：晨雾极轻地向峡谷深处移动，瀑布水雾略微扩散，右侧草叶有轻柔风动，天光只稍微变暖。摄影机做极慢、单向、连续推近，不旋转、不变焦跳跃。始终锁定山体地形、瀑布位置、人物位置、前景岩石、光源方向和左侧文案安全区。整段无切镜、无转场、无新增主体、无强闪烁、无地形融化、无人物移动、无文字、无 Logo、无水印；任意时间点构图都完整可读，适合页面滚动前进和反向查看。
```

失败降级：

```text
固定摄影机，锁定全部地形、人物和构图，只保留瀑布连续下落与一层非常轻微的峡谷薄雾移动，左侧文案安全区始终保持低细节。
```

## 4. 网页交付

- `hero-desktop.mp4`：1280×720，H.264，24fps，无音轨。
- `hero-mobile.mp4`：720×1280，主视觉围绕瀑布和人物重新裁切。
- `hero-poster.webp`：低动态模式和加载回退。

## 5. 失败修正

- 左侧过亮：压低安全区局部对比，禁止雾光进入标题区域。
- 地形漂移：固定摄影机，删除草叶运动，只保留瀑布。
- 滚动拖动卡顿：使用约 0.125 秒关键帧间隔重新编码，并限制前端 seek 频率。
